Finish attempt (header)
Optional placement of the Finish attempt action in the activity header — an alternative to the sticky-footer button. Shown when set via "Finish attempt button → Header action".

Manage dropdown
The activity's tabs — Settings, Question bank, Preview, Results, Overrides, Permissions, Backup — collapsed into one Manage menu (educator-only).
3
Questions in the course index
Each question is a nested item under the quiz in the course index — like book chapters — instead of a quiz-only progress grid in a block. (Alternative: switch "Question progress UI" to Progress bar.)
3
Survey-style progress (alternative)
A familiar survey pattern: an inline progress bar + "X of 8 answered" counter and numbered question chips (completed / current / flagged). The course index stays a plain activity row.
4
Linear navigation
Previous / Next and Finish attempt live in the course's sticky footer — the same linear nav used across the course — not a quiz-only nav block.
5
Multiple attempts
Resume / re-attempt and each attempt's grade are surfaced on the entry screen — a resume banner plus the previous-attempts table and highest-grade summary.
6
Summary & confirmation
Before submitting, a summary of every question's status, then a confirmation step that warns about any unanswered questions.
7
Sectioned, responsive settings
Every setting in one tabbed workspace; the form is sectioned with a sticky sub-nav that tracks scroll and reflows to a single column on small screens.
8
Question preview
Preview any question with the full behaviour + display options, technical info and Moodle-XML export — mirroring the question-bank preview page.
9
Prototype state switcher
A demo-only control (not a real feature) to jump between the quiz's states — attempt, summary, results — and the create / edit workspace tabs.
